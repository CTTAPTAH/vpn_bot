# Domain (Предметная область)

Слой domain содержит бизнес-модель системы и бизнес-правила.

Здесь находятся:

- Сущности (User, Plan, Subscription, Payment)
- Бизнес-логика
- Поведение объектов
- Перечисления (enums)
- DTO (если относятся к бизнес-уровню)

Этот слой НЕ должен зависеть от:

- Базы данных
- Telegram
- SQLAlchemy
- Внешних API
- Любых фреймворков

Domain — это чистая бизнес-логика приложения.
Он должен оставаться неизменным при смене БД, интерфейса или внешних сервисов.
