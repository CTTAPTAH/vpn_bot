# Infrastructure (Инфраструктура)

Слой infrastructure содержит техническую реализацию работы системы.

Сюда входят:

- ORM-модели (SQLAlchemy)
- Репозитории
- Реализация Unit of Work
- Работа с БД
- Клиент для XUI (VPN API)

Этот слой:

- Зависит от интерфейсов из application
- Может зависеть от domain
- Реализует абстракции

Infrastructure отвечает на вопрос:
«Как именно мы это делаем технически?»
