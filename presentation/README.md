# Presentation (Интерфейс пользователя)

Слой presentation отвечает за взаимодействие с пользователем.

В данном проекте это Telegram-бот.

Задачи:

- Принимать события (сообщения, callback-и)
- Вызывать соответствующие сценарии из application
- Формировать и отправлять ответы пользователю

В этом слое НЕ должно быть бизнес-логики.
Он только передаёт управление в application.
