# Application (Сценарии использования)

Слой application содержит use cases — конкретные действия системы.

Примеры:

- Покупка подписки
- Продление доступа
- Получение VPN-ключа
- Формирование меню

Задачи слоя:

- Управлять процессом выполнения сценария
- Использовать бизнес-логику из domain
- Работать через интерфейсы (репозитории, UoW, gateway)
- Управлять транзакциями

Этот слой зависит от:
- Domain
- Интерфейсов (contracts)

Он НЕ должен зависеть от конкретных реализаций инфраструктуры.
